# 周发布核对口径

## 来源与范围

- 时间：上一自然周周一 00:00 至周日 23:59（Asia/Shanghai），按业务字段中的发布日期判断。
- 客户事实：抖音客户发布表、小红书客户发布表。
- 机构事实：部门 Base 中当前全部“机构 X 焦尾 执行表”，基线 13 张。

## 比较字段

只比较会决定发布事实是否一致的字段：机构归属、达人名称、平台、发布日期、真实发布链接或作品 ID/GID，以及机构表进度是否为“已发布”。达人名称先做 NFKC、空格、分隔符和大小写归一化。点赞、评论、收藏、转发、互动总和不参与比较。

## 匹配与差异

匹配顺序：

1. 作品 ID/GID 相同；
2. 规范化真实发布链接相同；
3. 同机构、同平台、规范化达人名和发布日期同时相同；
4. 同机构、同平台、规范化达人名唯一命中时，可用于发现日期或链接差异。

抖音 `/user/...` 中的 `group_id`、`from_gid`、`vid` 应与 `/video/<id>` 归为同一作品；短链应展开后再比较。单元格标题、纯文本、富文本展示不同，但真实链接一致时不算差异。

差异类型包括：客户表有而机构表缺失、客户已发布而机构进度未更新、机构表已发布而客户表缺失、机构归属/达人/平台/发布日期/发布链接或作品 ID 不一致，以及多条候选无法消歧的待人工确认。

机构表中“已发布”但发布日期为空的记录，若能以作品 ID/链接与客户表上周记录命中，则正常参与核对；若没有任何周范围证据，不得擅自归入上周，也不得据此报客户表漏登。

## 防误报

- 机构是硬边界，但作品 ID/真实发布链接的强证据可以暴露“机构归属不一致”。
- 同达人多期合作不合并。
- 客户表同一作品重复行先按平台+作品 ID/规范化链接去重，并把重复情况记录为待核。
- 任一来源分页未读全、字段结构在分页期间变化、关键字段缺失或机构表不足 13 张时直接失败。普通协作编辑导致 revision 变化时，本轮已读分页组成只读快照，期间新增改动留给下一次核对，不因此整轮失败。
